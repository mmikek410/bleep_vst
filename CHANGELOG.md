# Changelog

## Sound Engine 2.0 — Phase A (FM, огибающая высоты, резонансный фильтр)

**Новый голос.** Цепочка: FM на двух операторах → резонансный фильтр → огибающая амплитуды.
- **FM:** RATIO 0.25–16 (гармонические и негармонические отношения), DEPTH (индекс 0–10), FEEDBACK (самообратная связь модулятора), DECAY (огибающая индекса: яркая атака, мягкий хвост). Velocity тоже влияет на яркость.
- **PITCH:** AMOUNT ±48 полутонов, DECAY, CURVE (от линейного спада к «лазеру»).
- **FILTER:** LP/BP, CUTOFF, RESO (с компенсацией пика, ниже самовозбуждения), ENV ±6 октав, DECAY.

**Качество звука.**
- FM-ядро работает с 2× передискретизацией, затем полуполосный дециматор (47 отводов). Индекс ограничен по правилу Карсона с учётом обратной связи. Алиасинг ниже −45…−50 дБ в полосе до 16 кГц. Это измерено полным FFT в тестах.
- Срез и глубина FM сглаживаются (5 мс), коэффициенты пересчитываются раз в 8 сэмплов (экономия CPU).
- Защитный «потолок» на выходе: до 0.8 сигнал не меняется, выше плавно ограничивается и никогда не превышает 1.0.

**Совместимость.**
- ID плагина (`Bl02`) и все старые ID параметров не изменились. Новые параметры добавлены, версия состояния стала 4.
- Проекты, сохранённые до Phase A, открываются с нейтральными FM и фильтром и звучат как раньше. Новый экземпляр плагина сразу звучит новым звуком.

**RANDOMIZE SOUND** теперь собирает согласованный патч: FM-отношение, глубину, обратную связь, огибающие, короткий «чирп» высоты и фильтр выше бочки и баса. Громкость, строй и sustain не трогает. UNDO возвращает всё.

**Интерфейс.** Панель SYNTH разбита на группы FM / PITCH / FILTER / AMP / OUT, добавлен переключатель LP/BP.

**Тесты.**
- Новые звуковые тесты: точность высоты (< 0.5 цента на 44.1/48/96 кГц), FM-спектры, алиасинг, огибающая высоты, крутизна фильтра, стресс со случайными экстремальными параметрами, отсутствие щелчков, CPU.
- Новые тесты плагина: звук старых проектов, сохранение версии 4, RANDOMIZE SOUND и UNDO, стресс во время воспроизведения.

**Демо.** Тестовый рендер: 8 тактов при 140 BPM с оригинальной синтезированной ударной петлёй. Варианты: старый синус для сравнения, ROUND, METALLIC, лазер, RESONANT и «резиновый» бип. Есть сухие версии без ударных.

**Откат.** Предыдущая рабочая сборка сохранена в ветке `release/m2-generative`.
