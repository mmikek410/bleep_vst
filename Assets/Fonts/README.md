The files are unmodified copies from the Google Fonts repository. They're compiled into the plug-in as binary data and loaded from memory, so nothing needs to be installed on the user's system. The OFL allows embedding and redistributing the fonts with software, commercial software included, as long as the copyright and licence notices travel with them. They are not sold on their own.
