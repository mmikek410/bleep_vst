# Прототипы звука: A / B / C (сравнение перед финальной версией)

Задача: более тёмный, глубокий, органичный бип для гипнотического техно. Один патч на весь секвенсор, без слоёв и без поклавишных тембров.

## Почему текущий движок звучит как «бип»

Измерения на значениях по умолчанию Phase A, нота C3:
- **Атака:** полная громкость за ~1 мс, затем сразу спад, без «плеча». Отсюда щелчковый аркадный старт.
- **Тело:** через 40 мс звук почти чистый синус: 3-я гармоника −36 дБ, остальные ниже −76 дБ. FM окрашивает только первые 20 мс.
- **Огибающая высоты:** +7 полутонов за 12 мс даёт «чирп», в форме волны видна квадратная атака.
- **Текстура:** нет ни шума, ни насыщения, ни пространства.

## Три подхода (tests/proto/Prototypes.h)

| | Идея | Ключевые элементы |
|---|---|---|
| **A. Dark FM** | FM с коротким пиком индекса и «телом» | индекс 2.2 -> 0.35 за ~35 мс, удар высоты +2 полутона за 8 мс, тёмный ФНЧ с ключевым слежением, округлая огибающая (атака 3 мс), мягкая асимметричная сатурация |
| **B. Resonant** | модальный синтез | импульс + 4-мс окрашенный шум возбуждают 3 резонатора (1:2:3, «полое дерево»); естественное затухание, демпфер по note-off, лёгкий «резиновый» спад высоты |
| **C. Hollow Analog** | «аналоговый» полый тон | треугольник + узкий импульс (polyBLEP), лёгкая перекрёстная модуляция, драйв перед резонансным ФНЧ, короткая огибающая фильтра |

Общие блоки (Source/dsp/Blocks.h, StereoDelay.h): TPT SVF, мягкая сатурация с единичным усилением малого сигнала, модальный резонатор, осцилляторы polyBLEP, перкуссионная огибающая с «плечом», дилэй с ФВЧ и ФНЧ в петле.

## Измерения (паттерн один и тот же, громкость выровнена по RMS −21 dBFS)

| Сухой бип | Пик/RMS | Атака (10–90 %) | Обертоны / основной | 400–1500 Гц | 1.5–4 кГц | CPU* |
|---|---|---|---|---|---|---|
| Текущий | 14.4 дБ | 0.7 мс | −8.0 дБ (только в атаке) | −12.4 дБ | −34.1 дБ | 0.8 % |
| A. Dark FM | 10.2 дБ | 3.1 мс | −1.4 дБ | −7.0 дБ | −29.7 дБ | 1.2 % |
| B. Resonant | 11.3 дБ | 4.1 мс | −9.4 дБ | −16.2 дБ | −40.8 дБ | 0.6 % |
| C. Hollow Analog | 10.7 дБ | 14.6 мс | −9.4 дБ | −15.2 дБ | −29.0 дБ | 1.3 % |

\* Плотная нагрузка (новая нота каждые 30 мс, до 8 голосов), 48 кГц, на облачной машине разработки. На Apple Silicon будет быстрее.

Клиппинга нет ни в одном из 18 рендеров. Пики после выравнивания громкости 0.20–0.55. Собственные уровни движков сильно различаются (RMS от −24 до −10 dBFS), поэтому финальной версии понадобится выравнивание громкости на каждый рецепт.

Это технические измерения, а не оценка звучания. Решение принимается на слух.
