BLEEP / 001 — macOS Apple Silicon (arm64) development build

There are two separate plug-ins, and you can install both at once:
  BLEEP 001          the current version, with the sequencer
  BLEEP 001 Classic  the original Phase 1 synth. Ableton sets saved with Phase 1 open with this one.

INSTALL
1. Open Terminal, type "cd " (with a space), drag this folder into the window, and press Enter. Then run:
       bash install.sh
   This copies the plug-in(s) in this folder to ~/Library/Audio/Plug-Ins/VST3 and
   /Components, removes the macOS download quarantine and re-signs them for local use.
   It only replaces a plug-in with exactly the same name, so the other version is not touched.

2. Ableton Live 12: Settings > Plug-Ins
   - Turn on "Use VST3 Plug-in System Folders"
   - Turn on "Use Audio Units v2" if you want the AU too
   - Click "Rescan"

3. Browser > Plug-Ins > BLEEP Audio > BLEEP 001 or BLEEP 001 Classic.

This is an unsigned (ad-hoc) development build.
